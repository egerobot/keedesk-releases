# Security

## Reporting a vulnerability

Please report security issues in KeeDesk privately to **info@egerobot.com** with the subject "KeeDesk security". Do not open a public GitHub issue for a vulnerability.

Include the KeeDesk version, your macOS version and the steps to reproduce. We acknowledge reports and keep you informed until the issue is resolved.

## Verifying installers

Only install KeeDesk from the Releases of this repository or from EGEROBOT's own pages. Check every download against the `SHA256SUMS` file of its release. macOS builds are signed with Developer ID: EGEROBOT OTOMASYON MUHENDISLIK PROJE DANISMANLIK SANAYI VE TICARET LIMITED SIRKETI (9S8KV52JV4) and notarized by Apple.

# Güvenlik

KeeDesk'teki güvenlik açıklarını lütfen **info@egerobot.com** adresine "KeeDesk güvenlik" konusuyla, gizli olarak bildirin; açık için herkese açık GitHub kaydı açmayın. KeeDesk sürümünü, macOS sürümünüzü ve adımları yazın. Kurulum dosyalarını yalnız bu deponun sürümlerinden ya da EGEROBOT'un kendi sayfalarından indirin ve `SHA256SUMS` ile doğrulayın.
